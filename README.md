I also build practical Python tools for Nuke and Nuke Studio: small utilities that reduce repetitive setup, make shot preparation cleaner, and help compositors move faster without losing control of the image.

## Focus

- VFX compositing for cleanup, keying, tracking, and integration
- Screen replacement, object removal, and difficult shot repair
- Nuke / Nuke Studio workflow tools
- Shot preparation, cut detection, and frame range utilities
- AI-assisted workflows when they help the final composite, not replace judgment

## Selected Tools

### CornerPin_Match

Nuke utility for resetting or reapplying corner pin data, especially when working with Mocha tracking data.

### cutdetective

Scene cut detection for video files, creating corresponding FrameRange nodes inside Nuke.

### cutdetective_studio

Nuke Studio version of the cut detection workflow for splitting video sequences into individual shots.

### clipboard_paster

Paste images or image sequences from the clipboard directly into Nuke, with automatic sequence detection.

### extractlayers

Creates Shuffle nodes for available layers, making multi-layer comps faster to set up.
