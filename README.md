## Pipeline Areas

### Nuke / Nuke Studio

Tools for compositing setup, tracking data handling, cut detection, shot splitting, layer extraction, and repetitive node graph tasks.

### DaVinci Resolve

Workflow support around conform, review exports, finishing checks, and moving shots between editorial, color, and compositing.

### ComfyUI

Controlled AI-assisted workflows for plate extension, cleanup exploration, restoration tests, and look development elements that can be brought back into a compositing pipeline.

## Selected Tools

### CornerPin_Match

Nuke utility for resetting or reapplying corner pin data, especially when working with Mocha tracking data.

### cutdetective

Scene cut detection for video files, creating corresponding FrameRange nodes inside Nuke.

### cutdetective_studio

Nuke Studio version of the cut detection workflow for splitting video sequences into individual shots.

### clipboard_paster

Paste images or image sequences from the clipboard directly into Nuke, with automatic sequence detection.

### extractlayers

Creates Shuffle nodes for available layers, making multi-layer comps faster to set up.
